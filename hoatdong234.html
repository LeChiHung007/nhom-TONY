Nút Bấm Tích Hợp Loading Thực Tế

Bấm thử nút trên để kích hoạt Spinner thu nhỏ ngay trong nút gửi dữ liệu (Mô phỏng xử lý bất đồng bộ).

📝 Code CSS chính của Hoạt động 2 (Refactored by Vũ Thành Uy)

/* 1. Tạo hình tròn bằng border-radius: 50% & tạo vệt xoay bằng border-top-color */
.spinner-cyber-classic {
  width: 58px;
  height: 58px;
  border-radius: 50%;
  border: 5px solid rgba(255, 255, 255, 0.12); /* Viền nền mờ */
  border-top-color: var(--accent-cyan);       /* Vệt xoay Xanh da trời tươi */
  border-right-color: var(--accent-purple);    /* Điểm xuyết Tím Neon sáng */
  filter: drop-shadow(0 0 10px rgba(56, 189, 248, 0.45));
  animation: cyber-spin 0.9s cubic-bezier(0.5, 0.1, 0.5, 0.9) infinite;
}

/* 2. Keyframes xoay đều 360 độ vô hạn */
@keyframes cyber-spin {
  0%   { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}

"AOS - Scroll Reveal" - Trải Nghiệm Cuộn Trang 3D Độc Đáo

Đổi mới toàn bộ các hiệu ứng cuộn trang sang dạng lật 3D (flip-left, flip-right, flip-up) và phóng to vút lên (zoom-in-up, zoom-in-down) mang lại cảm giác chuyển động đa chiều, khác biệt hoàn toàn với bản gốc.

💡
Prompt mẫu đề bài: "Hướng dẫn tôi cách tích hợp thư viện AOS vào file HTML thông qua CDN và cách thêm thuộc tính 'data-aos' vào các thẻ section để chúng hiện ra khi cuộn xuống."
1

Nhúng thư viện qua CDN

Thêm thẻ link CSS vào <head> và script JS vào trước thẻ đóng </body>: 

<!-- Trong thẻ <head> -->
<link rel="stylesheet" href="https://unpkg.com/aos@next/dist/aos.css" />

<!-- Trước thẻ đóng </body> -->
<script src="https://unpkg.com/aos@next/dist/aos.js"></script>
<script>
  AOS.init({ duration: 800, once: false });
</script>
2

Gắn thuộc tính data-aos mới

Sử dụng các hiệu ứng chuyển động 3D lật trang và zoom sâu độc đáo: 

<!-- Lật 3D không gian từ trái sang -->
<div data-aos="flip-left" data-aos-duration="850">Khối Card</div>

<!-- Phóng to vút từ dưới lên ngập tràn năng lượng -->
<div data-aos="zoom-in-up" data-aos-delay="200">Dự án</div>

<!-- Lướt chéo từ góc dưới bên phải -->
<div data-aos="fade-up-right">Tính năng</div>

Hoạt động 4 • 15 phút • Tối Ưu GPU 60 FPS

"Refactoring Performance" - Tối Ưu Hóa GPU Hardware

Giữ nguyên triết lý tối ưu: Thay đổi thuộc tính chuyển động từ top/left sang transform: translateX để xử lý trực tiếp trên GPU Compositor, đạt chuẩn 60 - 120 FPS mượt mà không gây nóng máy hao pin.

Đường Đua Hiệu Năng: CPU Reflow (Cũ) vs GPU Compositor (Sau Refactor)

Quan sát 2 đường đua bên dưới: Khối đỏ báo động di chuyển bằng left (ép CPU tính lại Layout & Repaint), còn phi thuyền ngọc lục bảo di chuyển bằng transform: translateX độc lập trên card đồ họa GPU.

⚠️ Trước Refactor (Bad Practice)

Sử dụng top / left

Kích hoạt chu trình Layout (Reflow) → Repaint ở mỗi frame. Gây nghẽn CPU, tụt FPS nghiêm trọng và giật lag trên điện thoại.

left: 10px → 80% (CPU Reflow) ⚠️ 24-30 FPS Drop
🐢
/* ❌ CHƯA TỐI ƯU: Thay đổi tọa độ hình học layout */
@keyframes move-bad {
  0%   { left: 10px; }
  100% { left: 80%; }
}
/* Trình duyệt phải tính toán lại kích thước và 
   vị trí của các phần tử xung quanh ở từng frame! */
✅ Sau Refactor (Best Practice)

Sử dụng transform: translateX

Chỉ kích hoạt tầng Compositing độc lập trên GPU. Bỏ qua hoàn toàn Layout và Repaint, đạt chuẩn 60 - 120 FPS siêu mượt.

transform: translateX() (GPU 60fps) ⚡ 60-120 FPS Smooth
🚀
/* ✅ TỐI ƯU: Xử lý phần cứng trực tiếp trên GPU */
@keyframes move-good {
  0%   { transform: translateX(0); }
  100% { transform: translateX(380px); }
}
/* will-change: transform đưa phần tử lên GPU Layer riêng, 
   tiết kiệm pin & siêu mượt trên màn hình 120Hz! */
Thuộc Tính CSS Layout (Reflow)? Repaint (Vẽ lại)? GPU Compositing? Đánh Giá Hiệu Năng
top, left, right, bottom Có (Cực nặng) Có Không (CPU) ⚠️ Giật khung hình trên mobile, nóng máy
width, height, margin, padding Có (Gây xô lệch) Có Không ⚠️ Tụt FPS nghiêm trọng ở thiết bị yếu
transform: translate(), scale(), rotate() Bỏ qua (0ms) Bỏ qua Có (GPU riêng) 🚀 Chuẩn 60 - 120 FPS, tối ưu phần cứng
opacity Bỏ qua Bỏ qua Có (GPU riêng) 🚀 Hiệu ứng mờ dần đỉnh cao không drop FPS
