"Loading Master" - Tạo Vòng Tròn Spinner

Sử dụng cú pháp @keyframes kết hợp border-top-color để tạo vòng tròn xoay 360 độ vô hạn làm Loading indicator cho trang Portfolio.

💡
Prompt mẫu: "Tạo một vòng tròn loading bằng CSS sử dụng animation xoay 360 độ vô hạn. Sử dụng border-top-color khác với các phần còn lại để tạo hiệu ứng xoay."

Spinner Chuẩn Đề Bài

Viền xám mờ + border-top-color xanh cyan xoay liên tục 360°.

Gradient Glow Spinner

Hiệu ứng phát sáng neon tím - hồng phù hợp với giao diện Dark Mode cao cấp.

Double Ring Spinner

Hai vòng lồng nhau xoay đảo chiều qua pseudo-element ::before & ::after.

Nút Bấm Loading Thực Tế

Bấm thử nút trên để kích hoạt Spinner thu nhỏ ngay trong nút gửi dữ liệu.

📝 Code CSS chính của Hoạt động 2

/* 1. Tạo hình tròn bằng border-radius: 50% và tạo vệt xoay bằng border-top-color */
.spinner-classic {
  width: 56px;
  height: 56px;
  border-radius: 50%;
  border: 5px solid rgba(255, 255, 255, 0.15); /* Vòng viền nền mờ */
  border-top-color: #06b6d4;                    /* Vệt xoay màu nổi bật */
  animation: spinner-rotate 1s linear infinite; /* Xoay đều vô hạn */
}

/* 2. Keyframes xoay 360 độ từ 0% đến 100% */
@keyframes spinner-rotate {
  0% {
    transform: rotate(0deg);
  }
  100% {
    transform: rotate(360deg);
  }
}

"AOS - Scroll Reveal" - Hiệu Ứng Khi Cuộn Trang

Tích hợp thư viện AOS (Animate On Scroll) vào dự án qua CDN để khi người dùng cuộn chuột, các khối giao diện sẽ xuất hiện sinh động (fade-in, slide-up, zoom).

💡
Prompt mẫu: "Hướng dẫn tôi cách tích hợp thư viện AOS vào file HTML thông qua CDN và cách thêm thuộc tính 'data-aos' vào các thẻ section để chúng hiện ra khi cuộn xuống."
1

Nhúng thư viện qua CDN

Thêm thẻ link CSS vào <head> và thẻ script JS vào trước thẻ đóng </body>: 

<!-- Trong thẻ <head> -->
<link rel="stylesheet" href="https://unpkg.com/aos@next/dist/aos.css" />

<!-- Trước thẻ đóng </body> -->
<script src="https://unpkg.com/aos@next/dist/aos.js"></script>
<script>
  AOS.init({ duration: 800, once: false });
</script>
2

Gắn thuộc tính data-aos

Thêm thuộc tính hoạt ảnh vào bất kỳ thẻ HTML nào bạn muốn tạo hiệu ứng khi cuộn: 

<!-- Hiện từ dưới lên -->
<div data-aos="fade-up">Nội dung</div>

<!-- Trượt từ trái sang kèm độ trễ -->
<div data-aos="fade-right" data-aos-delay="200">Card</div>

<!-- Phóng to dần -->
<div data-aos="zoom-in" data-aos-duration="1000">Ảnh</div>

"Refactoring Performance" - Tối Ưu Hóa Hiệu Năng

Hướng dẫn thay đổi thuộc tính chuyển động từ top/left sang transform: translate để AI và lập trình viên sinh ra code có hiệu năng tối đa (không gây giật lag trên điện thoại).

So Sánh Trực Quan: Cách Cũ vs Sau Refactor

Quan sát 2 đối tượng bên dưới: Khối đỏ di chuyển bằng left (bắt trình duyệt tính toán lại Layout & Paint), còn khối xanh di chuyển bằng transform: translate (chạy độc lập trên GPU Compositor).

⚠️ Trước Refactor (Bad Practice)

Sử dụng top / left

Kích hoạt chu trình Layout (Reflow) → Repaint liên tục ở từng frame. Làm CPU quá tải và gây giật khung hình (drop FPS) trên điện thoại.

left: 10px → 80% (CPU Reflow)
🐢
/* ❌ CHƯA TỐI ƯU: Thay đổi tọa độ layout */
@keyframes move-bad {
  0%   { left: 10px; }
  100% { left: 80%; }
}
/* Trình duyệt phải tính toán lại kích thước 
   và vị trí các phần tử xung quanh mỗi frame! */
✅ Sau Refactor (Best Practice)

Sử dụng transform: translate

Chỉ kích hoạt tầng Compositing trên GPU. Không tính lại layout, không vẽ lại giao diện, đảm bảo mượt mà 60 FPS chuẩn mực.

transform: translateX() (GPU 60fps)
⚡
/* ✅ TỐI ƯU: Xử lý trực tiếp trên GPU */
@keyframes move-good {
  0%   { transform: translateX(0); }
  100% { transform: translateX(380px); }
}
/* GPU Compositor xử lý độc lập, 
   tiết kiệm pin & siêu mượt trên Mobile! */
Thuộc Tính CSS Layout (Reflow)? Repaint (Vẽ lại)? GPU Compositing? Đánh Giá Hiệu Năng
top, left, right, bottom Có (Rất nặng) Có Không (CPU) ⚠️ Giật lag trên mobile, hao pin
width, height, margin, padding Có (Gây xô lệch) Có Không ⚠️ Tụt FPS nghiêm trọng
transform: translate(), scale(), rotate() Bỏ qua (0ms) Bỏ qua Có (GPU riêng) 🚀 Chuẩn 60 FPS, cực kỳ mượt
opacity Bỏ qua Bỏ qua Có (GPU riêng) 🚀 Hiệu ứng mờ dần hoàn hảo
